## 🔧 Customization Quick Reference

### Change Colors
Edit `css/style.css` (lines 8-22):
```css
:root {
    --primary-color: #2e61d2;    /* Main color */
    --accent-color: #ffbd03;     /* Accent color */
    /* Update these values */
}
```

### Change Text
Edit `index.html`:
- Line 36: Foundation name
- Line 90: Mission statement
- Line 92: Vision statement
- Line 296: Address
- Line 304: Phone
- Line 312: Email

### Change Images
Replace files in `images/` folder:
- `about-image.jpg` (600×600px)
- `gallery-*.jpg` (800×600px each)

### Add Sections
1. Add HTML to `index.html`
2. Add CSS to `style.css`
3. Add navigation link
